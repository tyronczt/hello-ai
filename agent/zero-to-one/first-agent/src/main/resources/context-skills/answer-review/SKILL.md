# 核对已有答案

## 执行流程

1. 列出候选答案中的项目事实，逐项找到实际读取的来源。
2. 把无法对应来源的判断标记为待核对；不要为了让答案完整而补写参数或默认值。
3. 检查是否把“未规定”写成具体数值，是否遗漏版本范围、失败结果或尚未解决的问题。
4. 按“已确认内容、来源、缺失信息”整理表达；不同来源存在冲突时先说明冲突。
5. 返回能够复核的候选答案，不把自己的检查结果当作新的业务资料。

## 边界与自查

本指导只检查表达与依据，不授予新增工具权限，也不执行本地脚本。
如果用户只问一个简单参数，保持简洁即可，不强制增加无关段落。
如果资料不足，应保留缺口；如果资料版本不一致，应保留版本区别。
不要把示例、模型推测或历史答案升级为当前文档事实；检查仍以本次实际取得的正文为准。

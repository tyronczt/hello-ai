## 🚀 学习路线

```
大模型与提示词基础 → 工具调用与 Agent Loop → 按需加入 RAG / 状态 → 评测与权限 → 框架与实战 → 面试复盘
```

初学者从 [Agent 入门总入口](agent/zero-to-one/README.md) 开始；RAG 是按任务需要补充的能力，不必先学完整套向量数据库再学习 Agent。
